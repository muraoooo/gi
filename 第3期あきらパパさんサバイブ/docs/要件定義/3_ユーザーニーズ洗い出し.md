# ユーザーニーズ洗い出し

ペルソナとユーザージャーニーマップに基づき、ユーザーが抱える課題とそれを解決するためのニーズを整理する。

## 1. コードレビューに関するニーズ

| 課題・悩み | 具体的なニーズ | 解決の方向性 |
| :--- | :--- | :--- |
| 自分のコードが正しいか不安 | 正誤だけでなく、より良い書き方（ベストプラクティス）を知りたい | AIによるコードレビュー機能<br>修正案の提示 |
| エラーの原因が分からない | エラーログの意味と解決策を分かりやすく教えてほしい | エラー解説機能<br>デバッグヒントの提示 |
| コードが汚い、可読性が低い | リファクタリングの提案が欲しい | 可読性向上のための具体的アドバイス |
| セキュリティが心配 | 脆弱性がないかチェックしてほしい | セキュリティチェック機能 |
| 質問するのが怖い、恥ずかしい | 誰にも気兼ねなく、何度でも質問したい | AIチャットボット形式のUI<br>優しいトーンでの回答 |

## 2. 学習・成長に関するニーズ

| 課題・悩み | 具体的なニーズ | 解決の方向性 |
| :--- | :--- | :--- |
| 同じミスを繰り返してしまう | 過去の指摘を振り返りたい | レビュー履歴の保存・閲覧機能 |
| 成長している実感がない | 自分のスキルアップを可視化したい | 学習記録ダッシュボード<br>レビュー回数等の統計表示 |
| 何を勉強すればいいか分からない | 次のアクションを提示してほしい | レビュー結果に基づく学習アドバイス |

## 3. サービス利用体験に関するニーズ

| 課題・悩み | 具体的なニーズ | 解決の方向性 |
| :--- | :--- | :--- |
| 待ち時間がストレス | すぐに結果を知りたい | 高速なAIモデル(Claude Haiku 4.5)の採用<br>ストリーミングレスポンス |
| 登録や設定が面倒 | すぐに使いたい | Googleログイン等のソーシャルログイン<br>シンプルなUI |
| スマホでも見たい | 移動中に復習したい | レスポンシブデザイン対応 |

## 4. 技術的要件への落とし込み

### 機能要件
- **コード入力・送信**: シンタックスハイライト付きのエディタ。
- **AIレビュー生成**: Claude Haiku 4.5 APIを利用したレビュー生成。
- **履歴管理**: MongoDBへのレビューデータ保存と参照。
- **ユーザー認証**: NextAuth.jsを用いた認証基盤。
- **通知**: レビュー完了時などのメール通知（Nodemailer）。

### 非機能要件
- **パフォーマンス**: レスポンスの高速化（App Router, Server Actions）。
- **UI/UX**: MUIを用いた直感的で美しいデザイン。
- **セキュリティ**: ユーザーコードの適切な取り扱い。
