# LP設計書

## 1. ページ構成

### 1.1 ヘッダー
- ロゴ（左側）
- ナビゲーション（機能、料金、お問い合わせ）
- ログイン/登録ボタン（右側）

### 1.2 ヒーローセクション
- **キャッチコピー**: 「あなたのコードが、もっと輝く。AIペアプログラミングで、確かな成長を。」
- **サブコピー**: 「プログラミング学習中のあなたに。Claude Haiku 4.5が、24時間365日、あなたのコードを優しく、的確にレビューします。」
- **CTAボタン**: 「無料でレビューを試す」
- **ビジュアル**: コードを書いている様子と、AIからのフィードバックが吹き出しで表示されているイラスト

### 1.3 サービスの特徴（3つのポイント）
1.  **高速・高精度なAIレビュー**
    - Claude Haiku 4.5を採用し、待ち時間なしで的確なフィードバックを提供。
2.  **初心者にも優しい解説**
    - 単なる正誤判定だけでなく、「なぜ良いのか」「どう直すべきか」を丁寧に解説。
3.  **成長の可視化**
    - 過去のレビュー履歴を保存し、自分のスキルアップを実感できる。

### 1.4 使い方ステップ
1.  **Step 1**: コードを入力または貼り付け
2.  **Step 2**: 「レビューする」ボタンをクリック
3.  **Step 3**: AIからのフィードバックを確認・修正

### 1.5 CTAセクション（ボトム）
- **メッセージ**: 「独学の不安を、自信に変えよう。」
- **CTAボタン**: 「今すぐ始める（無料）」

### 1.6 フッター
- 著作権表示
- 利用規約、プライバシーポリシーへのリンク
- SNSリンク

## 2. デザイン要件 (MUI)

### カラーパレット
- **Primary**: `#1976d2` (信頼感のあるブルー)
- **Secondary**: `#dc004e` (アクセントのピンク/赤)
- **Background**: ダークモード対応（黒ベースに少し明るいグレーのカード）

### タイポグラフィ
- **Font Family**: `Roboto`, `Helvetica`, `Arial`, sans-serif
- **Hero Title**: `h2` or `h1`, bold, responsive size
- **Section Title**: `h3`, center aligned

### コンポーネント
- `AppBar`, `Toolbar`: ヘッダー
- `Container`, `Box`, `Grid`: レイアウト
- `Typography`: テキスト
- `Button`: CTA
- `Card`, `CardContent`: 特徴紹介
- `Stepper` (optional) or simple list: 使い方

## 3. 実装ファイル
- `src/app/page.tsx`: LPのメイン実装
- `src/app/layout.tsx`: テーマプロバイダーの設定（MUIのセットアップ）
