   - エラーメッセージ: `Cannot find module 'next/server' imported from next-auth/lib/env.js`
   - NextAuth.js v5 (beta) と Next.js 14の互換性の問題の可能性
   - **対応が必要**: NextAuth.jsのバージョン確認または修正が必要

2. **環境変数の設定が必要**
   - `GOOGLE_CLIENT_ID` と `GOOGLE_CLIENT_SECRET` が設定されていない場合、Google認証が動作しません
   - `.env.local` ファイルにこれらの環境変数を設定する必要があります

3. **Google Cloud Consoleでの設定が必要**
   - OAuth 2.0 クライアントIDの作成
   - 承認済みのリダイレクトURIの設定（`http://localhost:3000/api/auth/callback/google`）
