## 3. メールアドレス形式エラー表示

### 確認手順
1. 名前、件名、本文に有効な値を入力

3. 「送信」ボタンをクリック

### 確認項目
- [ ] 無効なメールアドレス（例: `test@`）を入力 → 「有効なメールアドレスを入力してください」というエラーメッセージが表示される
- [ ] 無効なメールアドレス（例: `test@test`）を入力 → エラーメッセージが表示される
- [ ] 無効なメールアドレス（例: `test.com`）を入力 → エラーメッセージが表示される
- [ ] 無効なメールアドレス（例: `@test.com`）を入力 → エラーメッセージが表示される
- [ ] 有効なメールアドレス（例: `test@example.com`）を入力 → エラーメッセージが表示されない
- [ ] エラーメッセージが赤色で表示される
- [ ] 送信処理が実行されない（ページ遷移しない）

- [ ] `test@` → エラー表示
- [ ] `test@test` → エラー表示

- [ ] `@test.com` → エラー表示

## 6. MongoDBへのデータ保存確認

### 確認手順
1. MongoDB Atlasのクラスターに接続
2. データベースとコレクションを確認
3. 保存されたデータの内容を確認

### 確認項目
- [ ] MongoDB Atlasのクラスターに接続できる
- [ ] `contacts`コレクション（または`Contact`モデルで定義されたコレクション名）が存在する
- [ ] 送信したお問合せデータが保存されている
- [ ] 保存されたデータに以下のフィールドが含まれている:
  - [ ] `name`: 入力した名前
  - [ ] `email`: 入力したメールアドレス（小文字に変換されている）
  - [ ] `subject`: 入力した件名
  - [ ] `message`: 入力した本文
  - [ ] `createdAt`: 作成日時（自動設定）
- [ ] `createdAt`が正しい日時形式で保存されている
- [ ] 複数回送信した場合、すべてのデータが保存されている

### MongoDB Atlasでの確認方法
1. MongoDB Atlasにログイン
2. クラスターを選択
3. 「Browse Collections」をクリック
4. データベース名を選択（URIに指定されていない場合は`test`またはデフォルトDB）
5. `contacts`コレクションを選択
6. 保存されたドキュメントを確認

### テストケース
#### ケース1: 初回送信
- [ ] 1件目の送信 → MongoDBに1件のデータが保存される

#### ケース2: 複数回送信
- [ ] 2件目、3件目の送信 → MongoDBにそれぞれのデータが保存される

#### ケース3: データの整合性確認
- [ ] フォームに入力した内容とMongoDBに保存された内容が一致している
