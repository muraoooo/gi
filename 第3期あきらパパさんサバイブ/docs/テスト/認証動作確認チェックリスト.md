## 9. MongoDBにユーザー情報が保存されている

### 確認手順
1. MongoDB Atlasのクラスターに接続
2. データベースとコレクションを確認
3. 保存されたユーザー情報の内容を確認

### 確認項目
- [ ] MongoDB Atlasのクラスターに接続できる
- [ ] `users`コレクション（または`User`モデルで定義されたコレクション名）が存在する
- [ ] ログインしたユーザーの情報が保存されている
- [ ] 保存されたデータに以下のフィールドが含まれている:
  - [ ] `name`: Googleアカウントの名前
  - [ ] `email`: Googleアカウントのメールアドレス（小文字に変換されている）
  - [ ] `image`: Googleアカウントのプロフィール画像URL
  - [ ] `role`: ユーザー権限（デフォルト: 'user'）
  - [ ] `createdAt`: 作成日時（自動設定）
  - [ ] `updatedAt`: 更新日時（自動設定）
- [ ] `createdAt`が正しい日時形式で保存されている
- [ ] `updatedAt`が正しい日時形式で保存されている
- [ ] 同じメールアドレスで再度ログインした場合、新規作成されず既存のユーザー情報が更新される

### MongoDB Atlasでの確認方法
1. MongoDB Atlasにログイン
2. クラスターを選択
3. 「Browse Collections」をクリック
4. データベース名を選択（URIに指定されていない場合は`test`またはデフォルトDB）
5. `users`コレクションを選択
6. 保存されたドキュメントを確認

### テストケース
#### ケース1: 初回ログイン（新規ユーザー）
- [ ] 初めてログインするGoogleアカウント → MongoDBに新規ユーザーが作成される
- [ ] `createdAt`と`updatedAt`が同じ日時で保存される

#### ケース2: 既存ユーザーの再ログイン
- [ ] 既に登録済みのGoogleアカウントでログイン → 既存のユーザー情報が更新される
- [ ] `updatedAt`が更新される（`createdAt`は変更されない）

#### ケース3: ユーザー情報の更新
- [ ] Googleアカウントのプロフィール画像を変更 → 次回ログイン時に`image`フィールドが更新される
- [ ] Googleアカウントの名前を変更 → 次回ログイン時に`name`フィールドが更新される

#### ケース4: データの整合性確認
- [ ] Googleアカウントの情報とMongoDBに保存された情報が一致している
